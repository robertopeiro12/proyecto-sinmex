# T-28 · Tesorería: cuentas y saldo inicial — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que la oficina dé de alta las cuentas de dinero del negocio (de una sucursal o generales), fije su
saldo en una fecha y vea la Tesorería por día o rango, con Excel.

**Architecture:** Módulo `tesoreria` del backend (hoy vacío) con dos tablas (`tesoreria_cuenta`,
`tesoreria_saldo`), un controlador `/tesoreria`, un servicio que aplica el alcance por sucursal y una función pura
`saldoDeCuenta` (único lugar del cálculo; T-29 le agregará movimientos). En el portal, sección nueva
**Finanzas → Tesorería** con tres pestañas (Tesorería, Cuentas, Saldos).

**Tech Stack:** NestJS + Kysely + Postgres (Supabase local), class-validator, Jest (unit + e2e), pgTAP;
Next.js 15 + React 19 + Tailwind, Vitest + Testing Library; `exceljs` vía `apps/portal/src/lib/excel/`.

**Spec:** `docs/superpowers/specs/2026-10-15-t28-tesoreria-cuentas-saldo-inicial-design.md` (léelo antes de
empezar cualquier tarea).

## Global Constraints

- Dinero en la API: **centavos enteros** (`montoCentavos`, `saldoInicioCentavos`…). En la base `numeric(14,2)`.
  Convertir solo con `aCentavos` / `aPesos` de `apps/backend/src/modules/sincronizacion/dinero.ts`. Nunca `x * 100`.
- Tope de un monto: `MAX_CENTAVOS_TESORERIA = 99_999_999_999_999` (±999,999,999,999.99).
- "Hoy" = fecha de **Tijuana** calculada en Postgres: `to_char((now() at time zone 'America/Tijuana')::date, 'YYYY-MM-DD')`.
- Alcance por sucursal con `resolverAlcance` / `normalizarSucursalPedida` (`modules/sucursales/alcance-sucursal.ts`)
  y `buscarSucursalUsuario` (`modules/sucursales/buscar-sucursal-usuario.ts`).
- Nombre de cuenta: 1–60 caracteres tras recortar; único entre vivas por `lower(btrim(nombre))` en toda la empresa.
- Comentario de saldo: 1–200 caracteres o `null` (nunca `''`).
- Rango de la vista: `validarRango` de `modules/estadisticas/reglas-kilometraje.ts` (≤ 366 días).
- Todo borrado es **baja lógica** (`deleted_at`). Todo lector filtra `deleted_at is null`.
- Respuestas en camelCase. Mensajes al usuario en español, con acentos.
- El portal se usa en computadora: las tablas caben desde **1366 px** (≈1012 px de caja).
- **No se toca `apps/tablet`** ni el contrato de sincronización.
- Comandos siempre desde la raíz con `--workspace=…`. pgTAP: `npm run supabase -- test db`.

## Review Focus

1. **Usuario de Tijuana sobre una cuenta general** (la ve en la vista; editarla, borrarla o fijarle saldo → 403
   con mensaje claro, no 404 ni 500) — e2e en Tarea 3 y Tarea 4.
2. **Lote de saldos con una cuenta ajena o borrada en medio** → no se guarda **nada** (ni las filas válidas) — e2e
   en Tarea 4.
3. **Saldo fijado el día siguiente a `hasta`** no debe cambiar el "saldo al final" del rango — unitaria en Tarea 2
   y e2e en Tarea 5.
4. **Montos negativos y con coma de miles en el portal** (`-1,250.50`, `$-3`, `- 5`) se leen bien o se rechazan, nunca
   se guardan con el signo perdido — unitaria en Tarea 6.
5. **Renombrar una cuenta a un nombre que solo difiere en mayúsculas/espacios de otra viva** → 409 con mensaje, no
   500 — e2e en Tarea 3.

```sql
-- T-28: Tesoreria — cuentas (los "campos" del cliente) y saldos fijados.
-- Spec: docs/superpowers/specs/2026-10-15-t28-tesoreria-cuentas-saldo-inicial-design.md
--
-- Una cuenta es de una sucursal o general (sucursal_id null). Un saldo fijado es
-- el saldo real de una cuenta al INICIO de un dia: el primero es el saldo inicial
-- y los siguientes son "modificar saldo" (nuevo punto de partida). Los
-- movimientos (depositos, retiros, traspasos, cobranza) llegan en T-29.
-- Tablas nuevas y vacias: sin pre-flight contra la nube.

create table tesoreria_cuenta (
  id          uuid primary key default gen_random_uuid(),
  created_at  timestamptz not null default now(),
  updated_at  timestamptz not null default now(),
  deleted_at  timestamptz,
  nombre      text not null
    constraint ck_tesoreria_cuenta_nombre check (char_length(btrim(nombre)) between 1 and 60),
  sucursal_id uuid references sucursal(id)
);

create unique index uq_tesoreria_cuenta_nombre
  on tesoreria_cuenta (lower(btrim(nombre))) where deleted_at is null;

create trigger trg_tesoreria_cuenta_updated before update on tesoreria_cuenta
  for each row execute function set_updated_at();

create table tesoreria_saldo (
  id                 uuid primary key default gen_random_uuid(),
  created_at         timestamptz not null default now(),
  updated_at         timestamptz not null default now(),
  deleted_at         timestamptz,
  cuenta_id          uuid not null references tesoreria_cuenta(id),
  fecha              date not null,
  monto              numeric(14,2) not null,
  comentario         text
    constraint ck_tesoreria_saldo_comentario
      check (comentario is null or char_length(comentario) between 1 and 200),
  capturo_usuario_id uuid not null references usuario(id)
);

create unique index uq_tesoreria_saldo_cuenta_fecha
  on tesoreria_saldo (cuenta_id, fecha) where deleted_at is null;

create index ix_tesoreria_saldo_fecha
  on tesoreria_saldo (fecha) where deleted_at is null;

create trigger trg_tesoreria_saldo_updated before update on tesoreria_saldo
  for each row execute function set_updated_at();

-- El perfil `Administrador General` los recibe solo (PERFIL_MAESTRO,
-- apps/backend/src/modules/auth/permisos.ts). Grupo nuevo: Finanzas.
insert into permiso (clave, grupo, descripcion) values
  ('tesoreria.ver',       'Finanzas', 'Ver Tesorería'),
  ('tesoreria.gestionar', 'Finanzas', 'Tesorería: cuentas y saldos')
on conflict (clave) do nothing;
```

```ts
  armarVista,
  esFechaValida,
  ordenarCuentas,
  saldoDeCuenta,
  type BaseSaldo,
  type CuentaEnAlcance,
  type MovimientoSaldo,
  type SaldoFijado,
} from './reglas-saldo';

const base = (cuentaId: string, fecha: string, montoCentavos: number): BaseSaldo => ({
  cuentaId,
  fecha,
  montoCentavos,
});

const fijado = (
  id: string,
  cuentaId: string,
  fecha: string,
  montoCentavos: number,
  comentario: string | null = null,
): SaldoFijado => ({
  id,
  cuentaId,
  cuentaNombre: cuentaId === 'a' ? 'Efectivo TJ' : 'ScotiaFiscal',
  sucursalCodigo: cuentaId === 'a' ? 'TJ' : null,
  fecha,
  montoCentavos,
  comentario,
  capturo: 'Admin',
});

describe('esFechaValida', () => {
  it('acepta AAAA-MM-DD reales y rechaza lo demás', () => {
    expect(esFechaValida('2026-10-15')).toBe(true);
    expect(esFechaValida('2028-02-29')).toBe(true);
    expect(esFechaValida('2026-02-30')).toBe(false);
    expect(esFechaValida('2026-1-5')).toBe(false);
    expect(esFechaValida('hoy')).toBe(false);
  });
});

describe('saldoDeCuenta', () => {
  const saldos = [base('a', '2026-10-01', 1_000_000), base('a', '2026-10-10', 950_000)];

  it('sin saldo fijado en o antes de la fecha es null, no 0', () => {
    expect(saldoDeCuenta('a', '2026-09-30', 'inicio', saldos, [])).toBeNull();
    expect(saldoDeCuenta('a', '2026-09-30', 'final', saldos, [])).toBeNull();
    expect(saldoDeCuenta('otra', '2026-10-15', 'final', saldos, [])).toBeNull();
  });

  it('toma el saldo fijado más reciente con fecha <= D', () => {
    expect(saldoDeCuenta('a', '2026-10-05', 'inicio', saldos, [])).toBe(1_000_000);
    expect(saldoDeCuenta('a', '2026-10-10', 'inicio', saldos, [])).toBe(950_000);
    expect(saldoDeCuenta('a', '2026-10-12', 'final', saldos, [])).toBe(950_000);
  });

  it('el fijado vale al inicio de su día: los movimientos de ese día cuentan al final, no al inicio', () => {
    const movs: MovimientoSaldo[] = [{ cuentaId: 'a', fecha: '2026-10-10', montoCentavos: 50_000 }];
    expect(saldoDeCuenta('a', '2026-10-10', 'inicio', saldos, movs)).toBe(950_000);
    expect(saldoDeCuenta('a', '2026-10-10', 'final', saldos, movs)).toBe(1_000_000);
    expect(saldoDeCuenta('a', '2026-10-11', 'inicio', saldos, movs)).toBe(1_000_000);
  });

  it('los movimientos anteriores al saldo fijado no cuentan (nuevo punto de partida)', () => {
    const movs: MovimientoSaldo[] = [{ cuentaId: 'a', fecha: '2026-10-05', montoCentavos: -20_000 }];
    expect(saldoDeCuenta('a', '2026-10-09', 'final', saldos, movs)).toBe(980_000);
    expect(saldoDeCuenta('a', '2026-10-12', 'final', saldos, movs)).toBe(950_000);
  });

  it('un saldo fijado el día siguiente no se cuela en el final de D', () => {
    const conManana = [...saldos, base('a', '2026-10-13', 1)];
    expect(saldoDeCuenta('a', '2026-10-12', 'final', conManana, [])).toBe(950_000);
  });

  it('acepta montos negativos (sobregiro)', () => {
    expect(saldoDeCuenta('b', '2026-10-02', 'final', [base('b', '2026-10-01', -150_050)], [])).toBe(-150_050);
  });
});

describe('ordenarCuentas', () => {
  it('generales primero, luego por código de sucursal y nombre sin importar mayúsculas', () => {
    const ordenadas = ordenarCuentas([
      { nombre: 'efectivo', sucursalCodigo: 'TJ' },
      { nombre: 'Caja Chica', sucursalCodigo: 'TJ' },

      { nombre: 'ScotiaFiscal', sucursalCodigo: null },

      '- ScotiaFiscal',
      'MX Efectivo',
      'TJ Caja Chica',
      'TJ efectivo',
    ]);
  });
});

describe('armarVista', () => {
  const cuentas: CuentaEnAlcance[] = [
    { id: 'a', nombre: 'Efectivo TJ', sucursalId: 's-tj', sucursalCodigo: 'TJ' },
    { id: 'b', nombre: 'ScotiaFiscal', sucursalId: null, sucursalCodigo: null },

    const v = armarVista('2026-10-05', '2026-10-12', cuentas, [

    expect(v.total).toEqual({
      saldoInicioCentavos: 1_000_000,
      saldoFinalCentavos: 950_000,
      cuentasConSaldoInicio: 1,
      cuentasConSaldoFinal: 1,
      cuentas: 2,

        tipo: 'saldo-fijado',
        id: 's2',
        fecha: '2026-10-10',

        cuentaNombre: 'Efectivo TJ',

    expect(v.cuentas.find((c) => c.id === 'b')).toMatchObject({ saldoInicioCentavos: 300_000, saldoFinalCentavos: 300_000 });
    expect(v.eventos.map((e) => e.id)).toEqual(['s1']);
  });

  it('el total cuenta por separado las cuentas con saldo al inicio y al final', () => {
    const v = armarVista('2026-10-01', '2026-10-31', cuentas, [
      fijado('s1', 'a', '2026-09-01', 10_000),
      fijado('s2', 'b', '2026-10-20', -2_500),

    expect(v.total).toEqual({
      saldoInicioCentavos: 10_000,
      saldoFinalCentavos: 7_500,
      cuentasConSaldoInicio: 1,
      cuentasConSaldoFinal: 2,
      cuentas: 2,

      saldoFinalCentavos: 0,
      cuentasConSaldoInicio: 0,
      cuentasConSaldoFinal: 0,

  });
});
```

```ts
 * T-28 — el calculo del saldo de Tesoreria, en UN solo lugar.
 *
 * Un saldo fijado es el saldo real de una cuenta al INICIO de su dia (spec §3.3):
 * el primero es el saldo inicial y los siguientes son "modificar saldo", un nuevo
 * punto de partida. T-28 no tiene movimientos; T-29 alimentara `movimientos`
 * (depositos, retiros, traspasos, cobranza) sin cambiar esta firma.
 *
 * Todo en centavos enteros: nunca flotantes (ver sincronizacion/dinero.ts).
 */

/** ±999,999,999,999.99: lo que cabe en `numeric(14,2)`. */
export const MAX_CENTAVOS_TESORERIA = 99_999_999_999_999;

export type Momento = 'inicio' | 'final';

export interface BaseSaldo {
  cuentaId: string;
  /** `AAAA-MM-DD`. */
  fecha: string;
  montoCentavos: number;
}

export interface MovimientoSaldo {
  cuentaId: string;
  fecha: string;
  /** Con signo: positivo entra, negativo sale. */
  montoCentavos: number;
}

export interface CuentaEnAlcance {
  id: string;
  nombre: string;
  /** `null` = cuenta general (de toda la empresa). */
  sucursalId: string | null;
  sucursalCodigo: string | null;
}

export interface SaldoFijado extends BaseSaldo {
  id: string;
  cuentaNombre: string;
  sucursalCodigo: string | null;
  comentario: string | null;
  /** Nombre del usuario que lo capturo. */
  capturo: string;
}

export interface CuentaEnVista {
  id: string;
  nombre: string;
  sucursalCodigo: string | null;
  saldoInicioCentavos: number | null;
  saldoFinalCentavos: number | null;
}

export interface EventoTesoreria {
  /** T-29 agregara 'deposito', 'retiro', 'traspaso'… sin cambiar la forma. */
  tipo: 'saldo-fijado';
  id: string;
  fecha: string;
  cuentaId: string;
  cuentaNombre: string;
  montoCentavos: number;
  comentario: string | null;
  capturo: string;
}

export interface VistaTesoreria {
  desde: string;
  hasta: string;
  cuentas: CuentaEnVista[];
  total: {
    saldoInicioCentavos: number;
    saldoFinalCentavos: number;
    cuentasConSaldoInicio: number;
    cuentasConSaldoFinal: number;
    cuentas: number;
  };
  eventos: EventoTesoreria[];
}

const RE_FECHA = /^\d{4}-\d{2}-\d{2}$/;

/** `AAAA-MM-DD` de un dia que existe (2026-02-30 no). */
export function esFechaValida(fecha: string): boolean {
  if (!RE_FECHA.test(fecha)) return false;
  const d = new Date(`${fecha}T00:00:00Z`);
  return !Number.isNaN(d.getTime()) && d.toISOString().slice(0, 10) === fecha;
}

/**
 * Saldo de una cuenta al inicio o al final del dia `fecha`:
 *   base       = el saldo fijado mas reciente con fecha <= `fecha`
 *   inicio     = base + movimientos en [base.fecha, fecha)
 *   final      = base + movimientos en [base.fecha, fecha]
 * Sin base -> `null` ("Sin saldo inicial"), nunca 0. El final NO es "el inicio
 * del dia siguiente": un saldo fijado manana no debe colarse en el cierre de hoy.
 */
export function saldoDeCuenta(
  cuentaId: string,
  fecha: string,
  momento: Momento,
  saldos: BaseSaldo[],
  movimientos: MovimientoSaldo[],
): number | null {
  let baseActual: BaseSaldo | null = null;
  for (const s of saldos) {
    if (s.cuentaId !== cuentaId || s.fecha > fecha) continue;
    if (baseActual === null || s.fecha > baseActual.fecha) baseActual = s;
  }
  if (baseActual === null) return null;

  let total = baseActual.montoCentavos;
  for (const m of movimientos) {
    if (m.cuentaId !== cuentaId || m.fecha < baseActual.fecha) continue;
    const dentro = momento === 'inicio' ? m.fecha < fecha : m.fecha <= fecha;
    if (dentro) total += m.montoCentavos;
  }
  return total;
}

/** Generales primero; luego por codigo de sucursal y nombre (sin mayusculas). */
export function ordenarCuentas<
  T extends { nombre: string; sucursalCodigo: string | null },
>(cuentas: T[]): T[] {
  return [...cuentas].sort((a, b) => {
    if (a.sucursalCodigo !== b.sucursalCodigo) {
      if (a.sucursalCodigo === null) return -1;
      if (b.sucursalCodigo === null) return 1;
      return a.sucursalCodigo.localeCompare(b.sucursalCodigo);
    }
    return a.nombre.localeCompare(b.nombre, 'es', { sensitivity: 'base' });
  });
}

/**
 * La vista de `GET /tesoreria`. `saldos` son los fijados vivos de las cuentas en
 * alcance con fecha <= `hasta` (el repositorio ya filtro).
 */
export function armarVista(
  desde: string,
  hasta: string,
  cuentas: CuentaEnAlcance[],
  saldos: SaldoFijado[],
): VistaTesoreria {
  const movimientos: MovimientoSaldo[] = [];
  const filas: CuentaEnVista[] = ordenarCuentas(cuentas).map((c) => ({
    id: c.id,
    nombre: c.nombre,
    sucursalCodigo: c.sucursalCodigo,
    saldoInicioCentavos: saldoDeCuenta(c.id, desde, 'inicio', saldos, movimientos),
    saldoFinalCentavos: saldoDeCuenta(c.id, hasta, 'final', saldos, movimientos),
  }));

  const total = {
    saldoInicioCentavos: 0,
    saldoFinalCentavos: 0,
    cuentasConSaldoInicio: 0,
    cuentasConSaldoFinal: 0,
    cuentas: filas.length,
  };
  for (const f of filas) {
    if (f.saldoInicioCentavos !== null) {
      total.saldoInicioCentavos += f.saldoInicioCentavos;
      total.cuentasConSaldoInicio += 1;
    }
    if (f.saldoFinalCentavos !== null) {
      total.saldoFinalCentavos += f.saldoFinalCentavos;
      total.cuentasConSaldoFinal += 1;
    }
  }

  const eventos: EventoTesoreria[] = saldos
    .filter((s) => s.fecha >= desde && s.fecha <= hasta)
    .sort(
      (a, b) =>
        a.fecha.localeCompare(b.fecha) ||
        a.cuentaNombre.localeCompare(b.cuentaNombre, 'es', { sensitivity: 'base' }),
    )
    .map((s) => ({
      tipo: 'saldo-fijado',
      id: s.id,
      fecha: s.fecha,
      cuentaId: s.cuentaId,
      cuentaNombre: s.cuentaNombre,
      montoCentavos: s.montoCentavos,
      comentario: s.comentario,
      capturo: s.capturo,
    }));

  return { desde, hasta, cuentas: filas, total, eventos };
}
```

```ts
import { Inject, Injectable } from '@nestjs/common';
import { sql } from 'kysely';
import { DB_CONNECTION, type Database } from '../../database/database.tokens';
import { buscarSucursalUsuario } from '../sucursales/buscar-sucursal-usuario';
import { ordenarCuentas, type CuentaEnAlcance } from './reglas-saldo';

@Injectable()
export class TesoreriaRepository {
  constructor(@Inject(DB_CONNECTION) private readonly db: Database) {}

  private consultaCuentas() {
    return this.db
      .selectFrom('tesoreria_cuenta')
      .leftJoin('sucursal', 'sucursal.id', 'tesoreria_cuenta.sucursal_id')
      .select([
        'tesoreria_cuenta.id as id',
        'tesoreria_cuenta.nombre as nombre',
        'tesoreria_cuenta.sucursal_id as sucursalId',
        'sucursal.codigo as sucursalCodigo',
      ])
      .where('tesoreria_cuenta.deleted_at', 'is', null);
  }

  /**
   * Vivas en alcance. `codigoSucursal` null = todas; con codigo = las de esa
   * sucursal MAS las generales (spec §3.2).
   */
  async listarCuentas(codigoSucursal: string | null): Promise<CuentaEnAlcance[]> {
    let q = this.consultaCuentas();
    if (codigoSucursal !== null) {
      q = q.where((eb) =>
        eb.or([
          eb('sucursal.codigo', '=', codigoSucursal),
          eb('tesoreria_cuenta.sucursal_id', 'is', null),
        ]),
      );
    }
    return ordenarCuentas(await q.execute());
  }

  async buscarCuenta(id: string): Promise<CuentaEnAlcance | undefined> {
    return this.consultaCuentas().where('tesoreria_cuenta.id', '=', id).executeTakeFirst();
  }

  async crearCuenta(nombre: string, sucursalId: string | null): Promise<CuentaEnAlcance> {
    const { id } = await this.db
      .insertInto('tesoreria_cuenta')
      .values({ nombre, sucursal_id: sucursalId })
      .returning('id')
      .executeTakeFirstOrThrow();
    return (await this.buscarCuenta(id))!;
  }

  async renombrarCuenta(id: string, nombre: string): Promise<CuentaEnAlcance> {
    await this.db
      .updateTable('tesoreria_cuenta')
      .set({ nombre })
      .where('id', '=', id)
      .where('deleted_at', 'is', null)
      .execute();
    return (await this.buscarCuenta(id))!;
  }

  async eliminarCuenta(id: string): Promise<void> {
    await this.db
      .updateTable('tesoreria_cuenta')
      .set({ deleted_at: sql`now()` })
      .where('id', '=', id)
      .where('deleted_at', 'is', null)
      .execute();
  }

  async buscarSucursalUsuario(
    usuarioId: string,
  ): Promise<{ id: string | null; codigo: string | null } | undefined> {
    return buscarSucursalUsuario(this.db, usuarioId);
  }

  /** La fecha de hoy en Tijuana, del reloj de Postgres (nunca UTC). */
  async hoyEnTijuana(): Promise<string> {
    const r = await sql<{ hoy: string }>`
      select to_char((now() at time zone 'America/Tijuana')::date, 'YYYY-MM-DD') as hoy
    `.execute(this.db);
    return r.rows[0].hoy;
  }
}
```

```ts
const MENSAJE_DUPLICADA = 'Ya existe una cuenta con ese nombre.';
const MENSAJE_GENERAL = 'Las cuentas generales solo las administra un usuario General.';

/** `23505` unique_violation y `23503` foreign_key_violation (ver vehiculos.service.ts). */
function codigoPg(error: unknown): string | undefined {
  if (typeof error !== 'object' || error === null || !('code' in error)) return undefined;
  const code = (error as { code?: unknown }).code;
  return typeof code === 'string' ? code : undefined;
}

interface UsuarioSucursal {
  id: string | null;
  codigo: string | null;
}

@Injectable()
export class TesoreriaService {
  constructor(private readonly repo: TesoreriaRepository) {}

  async listarCuentas(usuarioId: string, sucursalPedida: string | null): Promise<CuentaEnAlcance[]> {
    const alcance = await this.alcanceDe(usuarioId, sucursalPedida);
    return this.repo.listarCuentas(alcance.tipo === 'todas' ? null : alcance.codigo);
  }

  async crearCuenta(usuarioId: string, dto: CrearCuentaDto): Promise<CuentaEnAlcance> {
    const usuario = await this.usuario(usuarioId);
    // Atado: la suya, se ignora lo que mande. General: lo que mande, o general.
    const sucursalId = usuario.id ?? dto.sucursalId ?? null;
    try {
      return await this.repo.crearCuenta(dto.nombre, sucursalId);
    } catch (error) {
      if (codigoPg(error) === '23505') throw new ConflictException(MENSAJE_DUPLICADA);
      if (codigoPg(error) === '23503') throw new BadRequestException('La sucursal no existe.');
      throw error;
    }
  }

  async renombrarCuenta(usuarioId: string, id: string, dto: RenombrarCuentaDto): Promise<CuentaEnAlcance> {
    await this.cuentaModificable(usuarioId, id);
    try {
      return await this.repo.renombrarCuenta(id, dto.nombre);
    } catch (error) {
      if (codigoPg(error) === '23505') throw new ConflictException(MENSAJE_DUPLICADA);
      throw error;
    }
  }

  async eliminarCuenta(usuarioId: string, id: string): Promise<void> {
    await this.cuentaModificable(usuarioId, id);
    await this.repo.eliminarCuenta(id);
  }

  /**
   * La cuenta viva que el usuario puede MODIFICAR (spec §3.2):
   *   - no existe / dada de baja / de otra sucursal -> 404 (no se revela)
   *   - general y el usuario esta atado a una sucursal -> 403
   */
  async cuentaModificable(usuarioId: string, cuentaId: string): Promise<CuentaEnAlcance> {
    const usuario = await this.usuario(usuarioId);
    const cuenta = await this.repo.buscarCuenta(cuentaId);
    if (!cuenta) throw new NotFoundException('No existe esa cuenta.');
    if (usuario.id !== null) {
      if (cuenta.sucursalId === null) throw new ForbiddenException(MENSAJE_GENERAL);
      if (cuenta.sucursalId !== usuario.id) throw new NotFoundException('No existe esa cuenta.');
    }
    return cuenta;
  }

  protected async usuario(usuarioId: string): Promise<UsuarioSucursal> {
    // El guard valido la FIRMA del token, no que el usuario siga existiendo.
    const fila = await this.repo.buscarSucursalUsuario(usuarioId);
    if (!fila) throw new UnauthorizedException('Sesion invalida.');
    return fila;
  }

  protected async alcanceDe(usuarioId: string, sucursalPedida: string | null): Promise<Alcance> {
    const usuario = await this.usuario(usuarioId);
    return resolverAlcance(usuario.codigo, sucursalPedida);
  }
}
```

```ts
   * Saldos fijados VIVOS de esas cuentas (y cuentas vivas), con fecha <= `hasta`
   * si viene. Mas recientes primero.

  async saldosDeCuentas(cuentaIds: string[], hasta: string | null): Promise<SaldoFijado[]> {
    if (cuentaIds.length === 0) return [];
    let q = this.db
      .selectFrom('tesoreria_saldo')
      .innerJoin('tesoreria_cuenta', 'tesoreria_cuenta.id', 'tesoreria_saldo.cuenta_id')
      .leftJoin('sucursal', 'sucursal.id', 'tesoreria_cuenta.sucursal_id')

      .select([

   * `uq_tesoreria_saldo_cuenta_fecha`: misma cuenta y fecha = corregir.

  async guardarSaldos(
    fecha: string,
    filas: { cuentaId: string; montoCentavos: number; comentario: string | null }[],
    usuarioId: string,
  ): Promise<boolean> {
    return this.db.transaction().execute(async (trx) => {
      const ids = filas.map((f) => f.cuentaId);
      const vivas = await trx
        .selectFrom('tesoreria_cuenta')
        .select('id')
        .where('id', 'in', ids)
        .where('deleted_at', 'is', null)
        .forUpdate()
        .execute();
      if (vivas.length !== new Set(ids).size) return false;

      for (const f of filas) {
        await trx
          .insertInto('tesoreria_saldo')
          .values({
            cuenta_id: f.cuentaId,
            fecha,
            monto: aPesos(f.montoCentavos),
            comentario: f.comentario,
            capturo_usuario_id: usuarioId,
          })
          .onConflict((oc) =>
            oc
              .columns(['cuenta_id', 'fecha'])
              .where('deleted_at', 'is', null)
              .doUpdateSet((eb) => ({
                monto: eb.ref('excluded.monto'),
                comentario: eb.ref('excluded.comentario'),
                capturo_usuario_id: eb.ref('excluded.capturo_usuario_id'),
              })),
          )
          .execute();
      }
      return true;
    });
  }

  async buscarSaldo(id: string): Promise<{ id: string; cuentaId: string } | undefined> {
    return this.db
      .selectFrom('tesoreria_saldo')
      .innerJoin('tesoreria_cuenta', 'tesoreria_cuenta.id', 'tesoreria_saldo.cuenta_id')
      .select(['tesoreria_saldo.id as id', 'tesoreria_saldo.cuenta_id as cuentaId'])
      .where('tesoreria_saldo.id', '=', id)
      .where('tesoreria_saldo.deleted_at', 'is', null)
      .where('tesoreria_cuenta.deleted_at', 'is', null)
      .executeTakeFirst();
  }

  async eliminarSaldo(id: string): Promise<void> {
    await this.db
      .updateTable('tesoreria_saldo')
      .set({ deleted_at: sql`now()` })
      .where('id', '=', id)
      .where('deleted_at', 'is', null)
      .execute();
  }
```

```ts
  /**
   * La pestaña Saldos: solo las cuentas que el usuario puede MODIFICAR (un usuario
   * atado no ve aqui las generales), con su saldo fijado en `fecha`, y la lista
   * de todos sus saldos fijados vivos (mas recientes primero).
   */
  async saldosDelDia(usuarioId: string, sucursalPedida: string | null, fecha: string): Promise<SaldosDelDia> {
    if (!esFechaValida(fecha)) throw new BadRequestException('La fecha no es válida.');
    const usuario = await this.usuario(usuarioId);
    const alcance = resolverAlcance(usuario.codigo, sucursalPedida);
    const visibles = await this.repo.listarCuentas(alcance.tipo === 'todas' ? null : alcance.codigo);
    const cuentas = usuario.id === null ? visibles : visibles.filter((c) => c.sucursalId !== null);
    const saldos = await this.repo.saldosDeCuentas(cuentas.map((c) => c.id), null);

    return {
      fecha,
      cuentas: cuentas.map((c) => {
        const delDia = saldos.find((s) => s.cuentaId === c.id && s.fecha === fecha);
        return {
          cuentaId: c.id,
          nombre: c.nombre,
          sucursalCodigo: c.sucursalCodigo,
          saldo: delDia
            ? { id: delDia.id, montoCentavos: delDia.montoCentavos, comentario: delDia.comentario }
            : null,
        };
      }),
      saldos,
    };
  }

  async guardarSaldos(usuarioId: string, dto: GuardarSaldosDto): Promise<{ guardados: number }> {
    if (!esFechaValida(dto.fecha)) throw new BadRequestException('La fecha no es válida.');
    const ids = dto.saldos.map((s) => s.cuentaId);
    if (new Set(ids).size !== ids.length) {
      throw new BadRequestException('Una cuenta viene dos veces en el lote.');
    }
    if (dto.fecha > (await this.repo.hoyEnTijuana())) {
      throw new BadRequestException('No se puede fijar un saldo en una fecha futura.');
    }
    // Antes de escribir nada: cualquier cuenta ajena (404) o general para un
    // usuario atado (403) tumba el lote completo.
    for (const id of ids) await this.cuentaModificable(usuarioId, id);

    const ok = await this.repo.guardarSaldos(
      dto.fecha,
      dto.saldos.map((s) => ({ cuentaId: s.cuentaId, montoCentavos: s.montoCentavos, comentario: s.comentario ?? null })),
      usuarioId,
    );
    if (!ok) throw new NotFoundException('Una de las cuentas ya no existe.');
    return { guardados: dto.saldos.length };
  }

  async eliminarSaldo(usuarioId: string, id: string): Promise<void> {
    const saldo = await this.repo.buscarSaldo(id);
    if (!saldo) throw new NotFoundException('No existe ese saldo.');
    await this.cuentaModificable(usuarioId, saldo.cuentaId);
    await this.repo.eliminarSaldo(id);
  }
```

```ts
function query(params: Record<string, string | null | undefined>): string {
  const p = new URLSearchParams();
  for (const [k, v] of Object.entries(params)) if (v) p.set(k, v);
  const texto = p.toString();
  return texto ? `?${texto}` : "";
}

/**
 * Monto tecleado -> centavos con signo, sin coma flotante. Acepta `$`, comas de
 * miles bien puestas y el `-` al frente (antes o despues del `$`). Vacio o mal
 * escrito -> `null`. Mismo criterio que `leerMontoCentavos` (lib/cobranzas.ts),
 * que no admite negativos ni el 0.
 */
export function leerMontoConSignoCentavos(texto: string): number | null {
  let limpio = texto.trim();
  let negativo = false;
  if (limpio.startsWith("-")) {
    negativo = true;
    limpio = limpio.slice(1).trim();
  }
  if (limpio.startsWith("$")) limpio = limpio.slice(1).trim();
  if (!negativo && limpio.startsWith("-")) {
    negativo = true;
    limpio = limpio.slice(1).trim();
  }
  if (!/^(\d{1,3}(,\d{3})+|\d+)(\.\d{1,2})?$/.test(limpio)) return null;
  const [enteros, decimales = ""] = limpio.replace(/,/g, "").split(".");
  const centavos = Number(enteros) * 100 + Number(decimales.padEnd(2, "0"));
  if (!Number.isSafeInteger(centavos) || centavos > MAX_CENTAVOS_TESORERIA) return null;
  return negativo && centavos > 0 ? -centavos : centavos;
}

/** Centavos al texto del campo (`"-1500.50"`). */
export function textoMontoConSigno(centavos: number): string {
  return centavos < 0 ? `-${textoMonto(-centavos)}` : textoMonto(centavos);
}

/** El dia anterior a `AAAA-MM-DD` (para el atajo "Ayer"). */
export function diaAnterior(fecha: string): string {
  const d = new Date(`${fecha}T00:00:00Z`);
  d.setUTCDate(d.getUTCDate() - 1);
  return d.toISOString().slice(0, 10);
}

const pesos = (centavos: number | null): string | number =>
  centavos === null ? "Sin saldo inicial" : centavos / 100;

/**
 * Una hoja (la utilidad de T-15 arma una sola): cuentas, Total Tesoreria y, si
 * hay, el bloque "Saldos fijados en el rango" reutilizando las columnas.
 */
export function definicionExcelTesoreria(
  vista: VistaTesoreria,
  filtros: { sucursal: string },
): DefinicionExcel {
  const filas: FilaExcel[] = vista.cuentas.map((c) => ({
    celdas: [c.nombre, etiquetaSucursalCuenta(c.sucursalCodigo), pesos(c.saldoInicioCentavos), pesos(c.saldoFinalCentavos), null],
  }));
  const t = vista.total;
  const conSaldo =
    t.cuentasConSaldoFinal === t.cuentas ? `${t.cuentas} cuentas` : `${t.cuentasConSaldoFinal} de ${t.cuentas} con saldo`;
  filas.push({
    celdas: ["Total Tesorería", conSaldo, t.saldoInicioCentavos / 100, t.saldoFinalCentavos / 100, null],
    tipo: "total",
  });
  if (vista.eventos.length > 0) {
    filas.push({ celdas: ["Saldos fijados en el rango", "Fecha", null, "Monto", "Comentario"], tipo: "grupo" });
    for (const e of vista.eventos) {
      const comentario = e.comentario ? `${e.comentario} · Capturó: ${e.capturo}` : `Capturó: ${e.capturo}`;
      filas.push({ celdas: [e.cuentaNombre, formatearFecha(e.fecha), null, e.montoCentavos / 100, comentario] });
    }
  }
  return {
    titulo: "Tesorería",
    filtros: [
      ["Rango", `${formatearFecha(vista.desde)} a ${formatearFecha(vista.hasta)}`],
      ["Sucursal", filtros.sucursal],
    ],
    columnas: [
      { encabezado: "Cuenta", tipo: "texto", ancho: 30 },
      { encabezado: "Sucursal", tipo: "texto", ancho: 18 },
      { encabezado: "Saldo al inicio", tipo: "pesos", ancho: 18 },
      { encabezado: "Saldo al final", tipo: "pesos", ancho: 18 },
      { encabezado: "Comentario", tipo: "texto", ancho: 40 },
    ],
    filas,
    nombreArchivo: `tesoreria-${vista.desde}-a-${vista.hasta}`,
  };
}
```

> con todas con saldo sale `"2 cuentas"`. Ajusta la prueba si cambias la frase, no al revés.

```tsx
import { Card, CardContent, CardHeader, CardTitle } from "@/components/ui/card";
import { useAuth } from "@/components/auth/auth-provider";
import { PestanaCuentas } from "./pestana-cuentas";
import { PestanaSaldos } from "./pestana-saldos";
import { PestanaVista } from "./pestana-vista";

type Pestana = "tesoreria" | "cuentas" | "saldos";
const TODAS: { clave: Pestana; texto: string; permiso: string }[] = [
  { clave: "tesoreria", texto: "Tesorería", permiso: "tesoreria.ver" },
  { clave: "cuentas", texto: "Cuentas", permiso: "tesoreria.gestionar" },
  { clave: "saldos", texto: "Saldos", permiso: "tesoreria.gestionar" },
];

/** Finanzas → Tesorería (T-28): ver, cuentas y saldos fijados. Pestañas como Facturas (T-19). */
export function PantallaTesoreria({
  sucursal,
  vistaInicial,
}: {
  sucursal: string | null;
  vistaInicial: string | null;
}) {
  const { puede, cargando } = useAuth();
  const pestanas = TODAS.filter((p) => puede(p.permiso));
  const [elegida, setElegida] = useState<Pestana | null>(null);
  const botones = useRef<Partial<Record<Pestana, HTMLButtonElement | null>>>({});

  if (cargando) return <Marco>Cargando…</Marco>;
  if (pestanas.length === 0) return <Marco>No tienes permiso para ver la Tesorería</Marco>;

  // La de la URL si se puede ver; si no, la primera permitida.
  const actual: Pestana =
    elegida ?? pestanas.find((p) => p.clave === vistaInicial)?.clave ?? pestanas[0].clave;

  function cambiar(clave: Pestana) {
    setElegida(clave);
    const params = new URLSearchParams(window.location.search);
    params.set("vista", clave);
    window.history.replaceState(null, "", `${window.location.pathname}?${params.toString()}`);
  }

  function alTeclear(evento: KeyboardEvent<HTMLDivElement>) {
    if (evento.key !== "ArrowLeft" && evento.key !== "ArrowRight") return;
    evento.preventDefault();
    const i = pestanas.findIndex((p) => p.clave === actual);
    const paso = evento.key === "ArrowRight" ? 1 : pestanas.length - 1;
    const siguiente = pestanas[(i + paso) % pestanas.length].clave;
    cambiar(siguiente);
    botones.current[siguiente]?.focus();
  }

  return (
    <Card>
      <CardHeader>
        <CardTitle>Tesorería</CardTitle>
      </CardHeader>
      <CardContent className="flex flex-col gap-4">
        <div role="tablist" className="flex gap-2" onKeyDown={alTeclear}>
          {pestanas.map(({ clave, texto }) => (
            <button
              key={clave}
              type="button"
              role="tab"
              id={`pestana-${clave}`}
              aria-controls={`panel-${clave}`}
              aria-selected={actual === clave}
              tabIndex={actual === clave ? 0 : -1}
              ref={(el) => {
                botones.current[clave] = el;
              }}
              onClick={() => cambiar(clave)}
              className={`rounded-md border px-3 py-1.5 text-sm ${actual === clave ? "bg-muted font-medium" : ""}`}
            >
              {texto}
            </button>
          ))}
        </div>
        {/* Una pestaña se monta la primera vez que se abre y se queda montada: volver no borra lo capturado. */}
        {pestanas.map(({ clave }) => (
          <div key={clave} role="tabpanel" id={`panel-${clave}`} aria-labelledby={`pestana-${clave}`} hidden={actual !== clave}>
            {clave === "tesoreria" && <PestanaVista sucursal={sucursal} />}
```

```tsx
"use client";

import { useCallback, useEffect, useRef, useState } from "react";
import { Button } from "@/components/ui/button";
import { mensajeDe } from "@/lib/api";
import { formatearFecha } from "@/lib/reportes";
import {
  eliminarSaldoFijado,
  etiquetaSucursalCuenta,
  guardarSaldos,
  leerMontoConSignoCentavos,
  obtenerSaldosDelDia,
  textoMontoConSigno,
  type SaldosDelDia,
} from "@/lib/tesoreria";
import { formatearPesos, hoyEnTijuana } from "@/lib/ventas";

interface Captura {
  monto: string;
  comentario: string;
  tocada: boolean;
}

/**
 * Fijar el saldo de las cuentas en una fecha (saldo inicial o "modificar saldo",
 * spec §3.3). Una fila por cuenta; solo se mandan las que cambiaron.
 */
export function PestanaSaldos({ sucursal }: { sucursal: string | null }) {
  const hoy = hoyEnTijuana();
  const [fecha, setFecha] = useState(hoy);
  const [dia, setDia] = useState<SaldosDelDia | null>(null);
  const [captura, setCaptura] = useState<Record<string, Captura>>({});
  const [cargando, setCargando] = useState(true);
  const [guardando, setGuardando] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const [aviso, setAviso] = useState<string | null>(null);
  const ultima = useRef(0);

  const cargar = useCallback(
    async (f: string) => {
      const esta = ++ultima.current;
      setCargando(true);
      setError(null);
      try {
        const r = await obtenerSaldosDelDia({ fecha: f, sucursal });
        if (esta !== ultima.current) return;
        setDia(r);
        setCaptura(
          Object.fromEntries(
            r.cuentas.map((c) => [
              c.cuentaId,
              {
                monto: c.saldo ? textoMontoConSigno(c.saldo.montoCentavos) : "",
                comentario: c.saldo?.comentario ?? "",
                tocada: false,
              },
            ]),
          ),
        );
      } catch (err) {
        if (esta !== ultima.current) return;
        setDia(null);
        setError(mensajeDe(err, "No se pudieron cargar los saldos."));
      } finally {
        if (esta === ultima.current) setCargando(false);
      }
    },
    [sucursal],
  );

  useEffect(() => {
    void cargar(fecha);
  }, [cargar, fecha]);

  function editar(cuentaId: string, campo: "monto" | "comentario", valor: string) {
    setAviso(null);
    setCaptura((prev) => ({ ...prev, [cuentaId]: { ...prev[cuentaId], [campo]: valor, tocada: true } }));
  }

  const cuentas = dia?.cuentas ?? [];
  const cambiadas = cuentas.filter((c) => {
    const k = captura[c.cuentaId];
    if (!k || k.monto.trim() === "") return false;
    const original = c.saldo ? textoMontoConSigno(c.saldo.montoCentavos) : "";
    return k.monto.trim() !== original || k.comentario.trim() !== (c.saldo?.comentario ?? "");
  });
  const invalida = (cuentaId: string) => {
    const k = captura[cuentaId];
    return !!k && k.monto.trim() !== "" && leerMontoConSignoCentavos(k.monto) === null;
  };
  const hayInvalidas = cuentas.some((c) => invalida(c.cuentaId));

  async function alGuardar() {
    setError(null);
    setAviso(null);
    if (cambiadas.length === 0) {
      setAviso("No hay cambios que guardar.");
      return;
    }
    setGuardando(true);
    try {
      const r = await guardarSaldos({
        fecha,
        saldos: cambiadas.map((c) => {
          const k = captura[c.cuentaId];
          const comentario = k.comentario.trim();
          return {
            cuentaId: c.cuentaId,
            montoCentavos: leerMontoConSignoCentavos(k.monto)!,
            ...(comentario ? { comentario } : {}),
          };
        }),
      });
      await cargar(fecha);
      setAviso(
        `Se ${r.guardados === 1 ? "guardó 1 saldo" : `guardaron ${r.guardados} saldos`} del ${formatearFecha(fecha)}.`,
      );
    } catch (err) {
      setError(mensajeDe(err, "No se pudieron guardar los saldos."));
    } finally {
      setGuardando(false);
    }
  }

  async function alEliminar(id: string, cuenta: string, f: string) {
    if (!window.confirm(`¿Eliminar el saldo de "${cuenta}" del ${formatearFecha(f)}? La Tesorería volverá a usar el anterior.`))
      return;
    setError(null);
    try {
      await eliminarSaldoFijado(id);
      await cargar(fecha);
    } catch (err) {
      setError(mensajeDe(err, "No se pudo eliminar el saldo."));
    }
  }

  return (
    <div className="flex flex-col gap-5">
      <div className="flex flex-wrap items-end gap-4">
        <div className="flex flex-col gap-1.5">
          <label htmlFor="saldo-fecha" className="text-sm font-medium">
            Fecha del saldo
          </label>
          <input
            id="saldo-fecha"
            type="date"
            required
            max={hoy}
            value={fecha}
            onChange={(e) => e.target.value && setFecha(e.target.value)}
            className="rounded-md border px-3 py-2 text-sm"
          />
        </div>
        <p className="max-w-xl text-xs text-muted-foreground">
          El saldo vale al <strong>inicio</strong> de ese día: lo que entre o salga ese mismo día se suma encima. El
          primero de cada cuenta es su saldo inicial; uno nuevo en otra fecha es el nuevo punto de partida.
        </p>
      </div>

      {error && (
        <p role="alert" className="text-sm text-destructive">
          {error}
        </p>
      )}
      {cargando && <p className="text-sm text-muted-foreground">Cargando…</p>}

      {!cargando && dia && cuentas.length === 0 && (
        <p className="text-sm text-muted-foreground">No hay cuentas que puedas modificar. Da de alta una en Cuentas.</p>
      )}

      {!cargando && dia && cuentas.length > 0 && (
        <>
```

```tsx
export function PestanaVista({ sucursal }: { sucursal: string | null }) {
  const { usuario } = useAuth();
  const hoy = hoyEnTijuana();
  const [desde, setDesde] = useState(hoy);
  const [hasta, setHasta] = useState(hoy);
  const [vista, setVista] = useState<VistaTesoreria | null>(null);
  const [cargando, setCargando] = useState(false);
  const [exportando, setExportando] = useState(false);

  const ultima = useRef(0);

  const consultar = useCallback(
    async (d: string, h: string) => {
      setError(null);
      if (d > h) {
        setError("La fecha inicial no puede ser posterior a la final.");
        return;
      }
      const esta = ++ultima.current;
      setCargando(true);
      try {
        const r = await obtenerTesoreria({ desde: d, hasta: h, sucursal });
        if (esta === ultima.current) setVista(r);
      } catch (err) {
        if (esta !== ultima.current) return;
        setVista(null);
        setError(mensajeDe(err, "No se pudo consultar la Tesorería."));

      await exportarExcel(

      );

      setError("No se pudo generar el Excel.");

      setExportando(false);

          </Button>

            Ayer
          </Button>
          <Button type="button" variant="ghost" size="sm" onClick={() => aplicar(rangoSemana(hoy))}>
            Esta semana
          </Button>
          <Button type="button" variant="ghost" size="sm" onClick={() => aplicar(rangoMes(hoy))}>

          </Button>

          Exportar a Excel
        </Button>
      </form>
```
